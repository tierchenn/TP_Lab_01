# TP_Lab_01

⚠️ Важно: программа собирает данные о вашем компьютере. А именно: тип OC, Модель CPU, число ядер, архитектура процессора, IP адрес, использование диска, региональные настройки языка и времени, температуру и имя user

Было решено использовать библиотеки:
platform: Кроссплатформенный доступ к информации об ОС, железе и версии системы. Работает одинаково на Windows/Linux/macOS, скрывая различия в API.
sys: Доступ к интерпретатору Python и его параметрам
os: Прямой интерфейс к операционной системе: работа с файлами, путями, процессами, переменными окружения.
soket: Сетевые функции, независимые от платформы.
shutil: Высокоуровневые операции с файлами и дисками.
locale: Доступ к региональным настройкам системы (язык, кодировка, формат чисел/дат).
time: Работа со временем и часовыми поясами.
json: Сериализация Python-объектов в формат JSON и обратно.

все модули являются стандартными
